# F-Lick-Out Cast Images

VRChat F-Lick-Outの外部キャスト画像2枚を配信するpublic repositoryです。このrepositoryの画像が正本です。Website側では管理しません。

- `cast01.webp`: 額縁1
- `cast02.webp`: 額縁2

毎開催、この2ファイルを上書きしてmainへpushしてください。ファイル名を変更しないでください。静止WebP、縦横とも2048以下、推奨サイズ1152×2048（9:16）です。正方形化・白余白追加は不要です。

現在の画像は既存World宣材から作成したテスト用です。開催前に確定した画像へ差し替えてください。公開画像なので、掲載許可を得た画像のみ使用してください。

公開URL:

- https://setohima.github.io/F-Lick-Out-Cast-Images/cast01.webp
- https://setohima.github.io/F-Lick-Out-Cast-Images/cast02.webp

GitHub Pagesはmainのrootから配信します。build systemはありません。独自domain・リダイレクト・version queryは使用しません。

更新後はPagesデプロイ完了と、固定URLから新画像が取得できることを確認してください。GitHub PagesのHTTP Cache-Controlは個別に制御できません。キャッシュと取得済みTextureにより、上書き直後の即時更新は保証されません。開催前に余裕をもって差し替え、新しいVRChat Instanceでも確認してください。Worldの再アップロードは不要です。
